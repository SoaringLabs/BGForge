# BGForge｜把玩家需要的功能加回来

**角色不用反复切，装备不用满屏找，心愿掉落不再错过。**

BGForge 是基于 **BGLite 2.4.0** 开发的泰坦重铸经典服社区增强版。在保留纯净、安全方向与基础拍卖体验的同时，重点补回并重做玩家呼声最高的实用功能。

## 1. 全角色总览

**不用挨个登录，也能看清本周进度。**

集中查看本机角色的团本 CD、周常与专业日常，以及金币、泰坦资源、专业和核心装备。

## 2. 专精装备过滤

**拍卖装备再多，也能一眼找到适合自己的。**

按坦克、治疗或输出等方案筛选装备：适合的保持高亮，不适合的自动置灰，并同步作用于拍卖表格、拍卖窗口和心愿单。

## 3. 个人心愿单

**提前选好目标，掉落和开拍时主动提醒。**

按副本与首领添加想要的装备。心愿掉落时提供文字和语音提醒，拍卖时显示醒目标记，获得后自动移出心愿单。

## 团本拍卖与账本

同时保留完整的团本拍卖、竞价记录、交易辅助、欠款管理与账单生成，并支持本地历史账本的保存和恢复。

## 使用方法

输入 **/bgf** 打开插件。

所有角色总览、心愿单与历史账本数据均保存在本机，不同步或传输无关玩家资料。

> BGForge 是独立插件，请勿与 BGLite 或 BiaoGe 同时启用。
