# BGForge

BGForge 是由 **Soaring Labs** 开发、基于 **BGLite 2.4.0** 的《魔兽世界》团本拍卖增强插件。

项目当前处于早期验证阶段，目标是在保持安全、稳定和基础拍卖能力的前提下，逐步补充更完整的团本拍卖与记账体验。

游戏内插件名称：`<BGForge> 团本事务台`

当前版本：`0.3.0`

版本变更参见 [CHANGELOG.md](CHANGELOG.md)。

## 当前状态

v0.3.0 扩展了全角色总览：

- 新增团本周常、祖格周常及珠宝、烹饪、钓鱼专业日常完成状态；
- 周常与专业日常使用二级表头，并可按组控制显示；
- 任务完成状态仅保存在本机角色总览记录中，不影响拍卖功能。

v0.2.0 回归了面向 Titan Reforged Classic 的精简装备过滤：

- 按当前职业手动选择职业或专精方案，不自动读取当前天赋；
- 不适合方案的装备会在当前表格、自动拍卖记录和正在拍卖窗口中置灰；
- 战网账号绑定装备始终保持高亮；
- 只保存按职业选择的方案，不保存角色名、服务器、GUID、天赋或物品记录；
- 不影响历史表格、拾取通知或装备库，也不会自动折叠拍卖窗口。

![BGForge Titan 装备过滤](docs/images/v0.2.0-spec-gear-filter.png)

此前已经完成 BGForge 的独立识别和基础品牌调整：

- 独立插件目录与入口文件 `BGForge/BGForge.toc`
- 插件列表、主界面、设置页及小地图入口统一使用 BGForge 名称
- 简体中文、繁体中文和英文基础说明同步更新
- 资源路径由 `BGLite` 调整为 `BGForge`
- 保留 BGLite 2.4.0 通信版本，便于后续验证兼容性
- 暂时保留原有 `BG` 全局对象和 `BiaoGe` 存档结构，降低早期改造风险

这一阶段以验证独立运行路线为主，尚未对核心拍卖流程进行大规模重构。

## 使用命令

在游戏聊天框中输入：

```text
/bgf
```

即可打开或关闭主界面。

目前还保留以下兼容命令：

```text
/bglite
/gbg
/biaoge
```

## 安装

1. 从 GitHub 下载或克隆本仓库。
2. 确保最终插件文件夹名称为 `BGForge`。通过 GitHub 下载 ZIP 时，可能需要把解压后的 `BGForge-main` 重命名为 `BGForge`。
3. 将整个 `BGForge` 文件夹放入对应魔兽客户端的插件目录：

   ```text
   World of Warcraft/<客户端目录>/Interface/AddOns/BGForge
   ```

4. 完全退出并重新启动游戏。
5. 在角色选择界面的插件列表中启用 `<BGForge> 团本事务台`。
6. 进入游戏后输入 `/bgf` 打开插件。

安装后的目录结构应类似：

```text
Interface/
└── AddOns/
    └── BGForge/
        ├── BGForge.toc
        ├── Core/
        ├── Libs/
        ├── Locales/
        └── Media/
```

## 与 BGLite、BiaoGe 的关系

BGForge 当前是基于 BGLite 源码发展的独立增强版本，不是需要同时加载 BGLite 的附加模块。

测试和使用 BGForge 时，请禁用 `BGLite` 与 `BiaoGe`。当前版本仍与它们共用部分全局对象、窗口名称、命令入口及存档结构，同时启用可能导致：

- 插件初始化顺序相互覆盖
- 主界面或按钮失效
- 拍卖消息被重复处理
- 设置和账本数据发生混乱

不需要删除原插件，在角色选择界面的插件列表中取消勾选即可。

## 开发方式

仓库根目录本身就是可安装的插件目录。修改代码后，将本目录同步到游戏的 `Interface/AddOns/BGForge`，然后在游戏内输入：

```text
/reload
```

即可加载大多数 Lua、XML 和本地化文本修改。首次安装、修改目录名称或 `.toc` 元数据后，完全重启客户端更稳妥。
